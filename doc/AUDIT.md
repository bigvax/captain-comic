## Выход после таблицы рекордов и тестовый Castle — 0.5.48

После ввода имени Enter сохраняет результат и переводит форму в показ таблицы.
Только следующая клавиша на уже показанной таблице закрывает приложение. Результат
ниже первой десятки сразу показывает таблицу; следующая клавиша также завершает
игру. Возврат с итоговой таблицы к финальной заставке и запуск новой игры удалены.
На таблице отображается «Любая клавиша — выход из игры». Повтор удерживаемой клавиши
не закрывает таблицу автоматически. Обычный просмотр рекордов с заставки/паузы
сохраняет прежнее поведение и не считается завершением игры.

Проверен весь переход через реальные SDL-события, включая ввод русского имени,
подтверждение формы, показ таблицы и завершение главного цикла следующей клавишей.
Отдельно проверяются Space, Esc, F2, F11; модульные проверки также охватывают Enter,
Num Enter, R, стрелки, Shift и Backspace. Подтверждение имени само по себе не выходит.

На стандартных картах: **67 сценариев, 74 488 проверок, 0 ошибок**.
После этого файлы CASTLE.TT2, CASTLE0.PT, CASTLE1.PT, CASTLE2.PT побайтно заменены
присланными пользователем тестовыми версиями. Пересобраны PAK, встроенный массив и
бинарники. Тестовый Castle изменяет геометрию и порог проходимости: полный набор
проверок исходных карт для него неприменим. С ним выполняются проверки загрузки
ресурсов, клавиатуры, финала и запуск локации. Перед релизом пользователь вернёт
стандартные файлы замка.

Предыдущие разделы ниже описывают историю 0.5.46–0.5.47; прежний переход из рекордов
в новую игру в 0.5.48 отменён согласно требуемому сценарию завершения.

## Исправления

- **Загрузка ресурсов.** Обычные сборки действительно читают внешний PAK.
  Standalone использует встроенный архив. Явный `--assets` имеет приоритет в обоих
  вариантах, принимает каталог или PAK и не маскирует ошибки встроенными файлами.
  Поиск внутри ZIP использует индекс miniz вместо перебора всех записей для каждого
  ресурса. Добавлены проверки размеров спрайтов, панорам, тайлов и координат мира;
  отсутствующие обязательные ресурсы не приводят к запуску частично загруженной игры.
- **Финал.** Удалены шесть глобальных переменных патча и отдельный цикл финала,
  обходивший штатные `--frames`, снимки экрана и обработку ввода. Состояние находится
  в `Game`, таймеры измеряются игровым временем, новая игра полностью его сбрасывает.
  Сохранены исчезновение героя, перевод жизней в очки и финальная заставка.
- **Важное изменение поведения финала:** корона теперь отмечается в инвентаре и
  обрабатывается обычным механизмом наград. Финал начинается при наличии всех трёх
  сокровищ, а не при одном факте подбора короны. При пересчёте жизней бонусные очки
  не создают новые жизни. После заставки Enter открывает штатную таблицу рекордов,
  после завершения ввода Enter начинает новую игру вместо принудительного выхода.
- **Рекорды.** Удалён отдельный обработчик из `main.c`. Редактор перенесён в
  `scores.c` и подключён к обычной обработке клавиш. Включается текстовый ввод SDL;
  Backspace удаляет символ UTF-8 целиком; длинный ввод не переполняет буфер;
  имена ограничены 16 символами. Очки не опускаются до нуля, отвергаемого форматом
  сохранений. Таблица сортируется в памяти с сохранением выбранной записи.
  Больше нет автоматической перезаписи файла выдуманными результатами при ошибке
  чтения. Восстановлены содержательные проверки некорректных файлов рекордов.
- **Сохранения.** Проверяются ошибки закрытия файла. В Windows используется
  `MoveFileEx` с заменой существующего файла: обычный CRT `rename` не позволял
  надёжно повторно сохранять рекорды и клавиши. Сохраняются прежние каталоги настроек.
- **Windows/DLL.** Настройка поиска DLL вынесена в CRT-конструктор, поскольку
  `SDL2main` обращается к SDL ещё до входа в `SDL_main`. Для каталога DLL применены
  широкие Windows API и проверка длины пути.
- **Рендер.** Исправлено чтение 256 байт из строки Label размером 160 байт при
  заполнении текстового кэша. Текстура счётчика очков принадлежит Resources и
  освобождается вместе с остальными ресурсами. Удалена неиспользуемая альтернативная
  функция показа заставок. Внешний вид обычного игрового кадра сохранён.
- **Завершение.** Добавлена единая очистка аудиоустройства, ресурсов, canvas,
  renderer и window на успешных и аварийных путях. Загрузка графики по-прежнему
  может выполняться повторно без уничтожения окна и звука.
- **CLI.** Исправлен приём пустых числовых аргументов; доступна четвёртая страница
  `--settings-screen 4`. Headless-запуск не требует инициализации аудиоустройства.
  Очки ограничены девятью десятичными цифрами.

## Сборка и удалённые рудименты

- Инкрементальная сборка с отдельными объектными файлами для каждого варианта;
  обычная и standalone-сборки могут выполняться параллельно.
- `make` по умолчанию собирает Linux. `make all` собирает четыре реальных варианта;
  `make static` создаёт совместимую копию linux-standalone, а не компилирует её снова.
- Генерация PAK и встроенного массива перенесена в `tools/pack_assets.py`.
  Архив воспроизводим, учитывает удаление файлов; неизменившиеся выходные файлы
  не переписываются. Встроенный массив объявлен `const` и нужен только standalone.
- Из сборки miniz исключены ненужные игре компрессор и API записи ZIP/zlib.
- Огромная Python-команда упаковки из Makefile заменена читаемым `tools/dist.py`.
  Упаковка не стирает весь `dist/`; изображения README включаются отдельными файлами.
  Рекорды и настройки пользователя в дистрибутивы не попадают.
- Исправлен `deps/linux/deps.sh`: работает независимо от текущего каталога,
  использует включённые исходники и не клонирует повторно зависимости.
- Удалены пустой `s.sh`, фиктивный `src/hud_icons.c`, неиспользуемые
  `assets/icons/enemies.png` и `assets/dos/WORLD.DAT`. Рабочее описание мира — JSON.
- Удалены повторные архивы и распакованные копии Windows SDK, ненужные Linux-сборке
  Xcode/VisualC-пакеты, вложенные истории git и кэши CMake с чужими абсолютными путями.
  Локальные исходники Linux-зависимостей, статические библиотеки, Windows sysroot,
  заголовки, DLL и сопроводительные лицензии оставлены. Отладочная информация Windows
  SDK удалена штатным MinGW strip. Каталог deps уменьшился примерно с 667 до 21 МБ.
- Исходные `data/keys.cfg` и `data/scores.dat` сохранены побайтно.

## Ограничения

Полное ручное прохождение игры не выполнялось. Windows-бинарники собраны и
проверены по таблицам импорта, но не запускались в Windows 11: результат нативного
запуска и работу устройств ввода/звука нужно проверить на целевой системе.

Linux standalone/static не является полностью статическим ELF: SDL2, SDL2_ttf,
SDL2_image, FreeType и кодеки включены статически, но системные оконные, звуковые
библиотеки и glibc остаются динамическими. Это соответствует фактической прежней
сборке; теперь ограничение явно отражено в README.
