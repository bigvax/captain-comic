# История изменений Captain Comic

Текущая версия игры: **0.5.63**.

[Описание, управление и сборка](README.md) · [Проверки и результаты](AUDIT.md)

Здесь перечислены изменения проекта. Подробности проверок, их результаты
и ограничения сохранены в AUDIT.md.

## 0.5.63

- Подготовлены настройки Git и workflow автоматических Linux-проверок для GitHub.
- Добавлены готовые Linux-библиотеки и Windows SDK из пользовательских архивов.

- Подключена пользовательская редакция README и добавлено прохождение WALKTHROUGH.
- В прохождении согласованы названия локаций и предметов, номера экранов пещеры
  и условие завершения игры в порте. Версия игры сохранена.

- Список в плашке паузы поднят и центрирован между заголовком и нижней рамкой.
- Клавиши выделены жёлтым; тире и названия действий выровнены по колонкам.
- Документация разделена: постоянное описание — README, история — CHANGELOG,
  технические проверки — AUDIT. Версия игры при разделении не менялась.

## 0.5.62

- Плашка паузы уменьшена с 240×64 до 180×60 логических пикселей.
- Подсказки размещены четырьмя строками: Esc / P — продолжить,
  Q / Й — выход, R / К — рекорды, F1 — справка.

## 0.5.61

- Удалена устаревшая чёрная плашка, закрывавшая низ конечной заставки.
- В таблицу локаций README добавлены восемь иконок 32×32.

## 0.5.60

- Значки жизней выводятся строго 32×32 пикселя окна с промежутком 8 пикселей.
- В узких окнах скрытый запас жизней показывается числом `+N`.
- Исключены дробное масштабирование значков и пересечение окружностей с рамкой.

## 0.5.59

- Заставка-справочник `assets/intro/legend.png` заменена пользовательским изображением.
- Обновлены внешний пакет ресурсов и standalone-сборки.

## 0.5.58

- Название Castle сокращено до «Замок» в интерфейсе, справке и документации.
- Без смены версии обновлён HUD-атлас; иконки жизней выделены в отдельные
  текстуры для устранения тёмной каймы и примеси соседних ячеек.

## 0.5.57

- По данным игры уточнено количество щитов: 11 в восьми локациях.
- В README добавлены ориентиры и координаты всех щитов; обновлена справка.

## 0.5.56

- Добавлен иллюстрированный справочник всех десяти видов предметов.
- Обновлены игровые описания и справка; уточнены экраны золота и палочки в пещере.

## 0.5.55

- Обновлены иконки интерфейса и локаций.
- На странице локаций F4 добавлен выбор строк стрелками с подсветкой,
  Home/End и подтверждением Enter, Num Enter или Пробелом.
- Сохранён быстрый переход цифрами 1–8.

## 0.5.54

- Установлены полные названия локаций: Скалистый лес, Озеро Сири,
  Пещера слепых жаб, Ангар, Космическая база, Луна Тамби, Комплекс, Замок.

## 0.5.53

- Удалена подсказка «Пробел / Enter — таблица рекордов» на конечной заставке.
- Переход к рекордам работает по любой новой клавише, без автоповтора.
- При попадании в десятку открывается ввод имени, иначе сразу таблица.
  Следующая клавиша после таблицы завершает игру.

## 0.5.52

- В игре и редакторе согласованы порядок и названия восьми локаций.
- Сохранены внутренние идентификаторы и имена файлов уровней.

## 0.5.51

- Убрано жёсткое ожидание порога проходимости оригинального Castle
  из встроенных проверок; проверяется допустимость порога загруженного TT2.
- Выполнена проверка проекта, сборки и состава ресурсов; подробности — в AUDIT.md.

## 0.5.50

- В редакторе рекордов Shift + Влево/Вправо увеличивает шаг изменения очков в десять раз.

## 0.5.49

- Получение Короны обязательно запускает финал независимо от других предметов.
- Перед заставкой оставшиеся жизни пересчитываются в очки.

## 0.5.48

- Исправлен выход после показа таблицы рекордов вместо возврата к заставке.
- Подключены пользовательские ресурсы Castle для быстрого тестирования.

## 0.5.47

- Исправлена обработка конечной заставки и перехода к таблице рекордов.
