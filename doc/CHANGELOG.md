# История изменений Captain Comic

Текущая версия игры: **0.5.64**.

[Описание, управление и сборка](README.md) · [Проверки и результаты](AUDIT.md)

Здесь перечислены изменения проекта. Подробности проверок, их результаты
и ограничения сохранены в AUDIT.md.

## 0.5.64

- Добавлены цели автоматизации управления версиями и публикации релизов на GitHub в `Makefile`: `make bump-patch`, `make bump-minor`, `make bump-major` (с единым источником правды в `src/cc.h`) и `make release` (прогон тестов, сборка Linux x64, Windows x64 и WebAssembly, создание тега и загрузка артефактов через `gh release`).
- Добавлен шаблон описания релизов `packaging/RELEASE_NOTES.md` с подробным описанием вариантов поставки.
- В `deps/linux/deps.sh` и `Makefile` добавлена сборка статической библиотеки `libSDL2.a` из локальных исходников для автономной сборки `captain-comic-standalone` в современных дистрибутивах Linux без системного `libSDL2.a`.
- Устранено падение (`SIGSEGV`) в интеграционном тесте `tools/ending_loop_check.c` поверх прослойки `sdl2-compat` (`libSDL3`) путём прямого связывания со статической `libSDL2.a` и инициализации `SDL_StartTextInput()`.
- Добавлена линковка математической библиотеки (`-lm`) для статических архивов `libpng16.a` и `libSDL2.a` в `LINUX_STATIC_LIBS`.

## 0.5.63

- Добавлена браузерная сборка WebAssembly (`make web`) из общего кода C11 / SDL2.
- Игровой цикл адаптирован к requestAnimationFrame; запуск звука выполняется после нажатия «Играть».
- Рекорды и настройки клавиш сохраняются в браузере. Добавлены кнопки управления и полноэкранный режим; при скрытии вкладки игра ставится на паузу.

- Исправлены Ins/Del цифрового блока в редакторе рекордов F4 при выключенном Num Lock.
- При заполненной таблице редактор предлагает сначала удалить запись клавишей Del.
- Ctrl+Влево/Вправо меняет очки с шагом ×100; Shift сохраняет шаг ×10.
- Подсказки редактора рекордов сокращены до двух строк под таблицей; клавиши редактирования выделены жёлтым, глобальные — бирюзовым. Высота строк списка увеличена.

- Подготовлены настройки Git и workflow автоматических Linux-проверок для GitHub.
- Добавлены готовые Linux-библиотеки и Windows SDK из пользовательских архивов.

- Подключена пользовательская редакция README и добавлено прохождение WALKTHROUGH.
- В прохождении согласованы названия локаций и предметов, номера экранов пещеры
  и условие завершения игры в порте. Версия игры сохранена.

- Список в плашке паузы поднят и центрирован между заголовком и нижней рамкой.
- Клавиши выделены жёлтым; тире и названия действий выровнены по колонкам.
- Документация разделена: постоянное описание — README, история — CHANGELOG,
  технические проверки — AUDIT. Версия игры при разделении не менялась.

## 0.5.62

- Плашка паузы уменьшена с 240×64 до 180×60 логических пикселей.
- Подсказки размещены четырьмя строками: Esc / P — продолжить,
  Q / Й — выход, R / К — рекорды, F1 — справка.

## 0.5.61

- Удалена устаревшая чёрная плашка, закрывавшая низ конечной заставки.
- В таблицу локаций README добавлены восемь иконок 32×32.

## 0.5.60

- Значки жизней выводятся строго 32×32 пикселя окна с промежутком 8 пикселей.
- В узких окнах скрытый запас жизней показывается числом `+N`.
- Исключены дробное масштабирование значков и пересечение окружностей с рамкой.

## 0.5.59

- Заставка-справочник `assets/intro/legend.png` заменена пользовательским изображением.
- Обновлены внешний пакет ресурсов и standalone-сборки.

## 0.5.58

## 0.5.55
