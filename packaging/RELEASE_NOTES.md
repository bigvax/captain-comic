## Captain Comic v__VERSION__ — нативная версия на C11 / SDL2

Классический платформер **Captain Comic** (1988, Michael Denio), полностью переписанный на чистый **C11 + SDL2** с поддержкой современного разрешения, плавной отрисовки, звука, таблицы рекордов и русскоязычного интерфейса.

### Что входит в релиз (выберите подходящий вариант)

* **`captain-comic-linux-x64-standalone.tar.gz`** — автономная сборка для **Linux x64** (все ресурсы и библиотеки `SDL2`, `SDL2_ttf`, `SDL2_image` вшиты внутрь исполняемого файла; не требует установки дополнительных пакетов).
* **`captain-comic-linux-x64-static.tar.gz`** — статическая Linux-сборка со вшитыми зависимостями для запуска в окружениях без системных библиотек SDL2.
* **`captain-comic-linux-x64.tar.gz`** — компактная сборка для **Linux x64**, использующая системные библиотеки `libsdl2-2.0`, `libsdl2-ttf-2.0` и `libsdl2-image-2.0`.
* **`captain-comic-win64-standalone.zip`** — автономный `.exe`-файл для **Windows x64** с упакованными внутри ресурсами (запускается одним файлом без установки).
* **`captain-comic-win64.zip`** — портативная сборка для **Windows x64** (`.exe` + необходимые `.dll` и папка ресурсов).
* **`captain-comic-web.zip`** — сборка для браузера (**WebAssembly / HTML5**), готовая к размещению на любом статическом веб-сервере.

### Быстрый запуск

* **Linux:** распакуйте архив и запустите `./captain-comic` (для справки по параметрам командной строки — `./captain-comic --help`).
* **Windows:** распакуйте архив и запустите `captain-comic.exe`.
